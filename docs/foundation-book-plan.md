# 『5分間英単語』を起点にした基礎学習の案

調査・設計メモ。登録制限、写真取り込み、教材追加、AI接続はこの変更では実装していない。対象は元の寿司タイプ。

## 公開資料で分かったこと

対象書籍は高橋敏之著『話す力が身につく 5分間英単語』（ダイヤモンド社、2023年2月、ISBN 9784478110751）。出版社の紹介・目次と、著者による公開抜粋記事を確認した。書籍全体を読了した調査ではなく、ユーザーの写真もまだ受け取っていない。

目次は、基本動詞の用法、意味の近い語の比較、語の中心的な意味・語源という3つのまとまりで、番号付き項目は全200ユニット。takeは複数ユニットに分かれ、後半にはwithdrawやundergoなども掲載される。「基礎動詞だけの200単語」ではない。公開抜粋でも、既知の動詞を文脈に合う形で使い分ける課題が示されている。

このため、見出し語や品詞だけで全項目を「初級」とみなさず、用法と学習上の役割を確認して分類する。公開資料だけから本文の全表現や各ユニットの具体的な到達条件を推定しない。

## ユーザー原案と、推奨する進め方

原案は「この本の表現を先に身につけ、すべてクリアしたら英検準1級・1級相当の語を追加できるようにする」。まず使える基本表現を増やす、という方向を出発点にする。

推奨案は、**基礎を優先して進め、関連する用法の習得に合わせて発展表現を解放する**方式。登録したい語はいつでも保存できる「あとで学ぶ」欄を用意し、学習開始の条件と保存の可否を分ける。出会った語を忘れずに残せる。

- 本の学習項目から、基礎として必修にする用法を選ぶ。全ページの全単語を必修にしない。
- まずその必修用法を練習する。進捗は「全体のうち後日も思い出せた用法がいくつか」で見せる。
- 発展表現に必要な基本用法を確認できたら、その表現を少しずつ混ぜる。関係のない難語の未習得で、全体の進行を止めない。
- 本の全項目を進める達成目標も残す。「基礎の修了」と「本の全項目への取り組み」は別に表示する。

登録を全面的にロックするか、関連用法ごとの解放にするかは未決定。この調査だけで原案のロックを実装・変更しない。基礎を先に学ぶ順序が、誰にとっても英検対策の最短経路になるという実証は今回確認していない。試験向けには別途、読解・聴解や試験固有の練習も必要になる。

## 本に出てくる難しい語の扱い

重要なのは品詞よりも、**その問題で何を覚えたいか**。AIは次の候補を提案し、人が確認できる形にする。

| 問題内の役割 | 扱い |
| --- | --- |
| 今回覚える基本用法・語の組み合わせ | 必修の学習対象。意味・場面から取り出す練習をする |
| 例文の内容を成立させる周辺語 | 意味を添える、既知の語へ変える、画面に表示しておく。対象用法の習得条件から分ける |
| 今回の主題でもある難しい語・用法 | 発展側の学習対象として保持し、自然な基本表現からつなぐ |

説明用の独自例：`take ... seriously` を練習するとき、例文の `proposal` が分からなければ「proposal＝提案」を表示したり、文脈を示して `take it seriously` から練習したりできる。`proposal` の綴りを思い出せないことだけで、このtakeの用法を未習得にしない。

一方、`make a reservation` を学ぶ問題では、reservationも組み合わせの中心になる。この場合は名詞の意味を先に確認し、まとまりとして練習する。名詞を一律に取り除いたり、どの単語でも代名詞へ置き換えたりしない。

易しくする際も、対象の意味・文型・語の組み合わせ・使用条件を残す。難しい周辺語を置き換えた結果、元の学習対象が消えたものは同じ確認問題として扱わない。

## 修了は「用法を後日も取り出せた」で判定する

- まず日本語の意味や短い場面から、対象の英語表現を入力する。見えている英文の写し打ちだけで修了にしない。
- 頭文字・文字数・追加ヒントの有無を記録する。周辺語の意味表示と、答えそのもののヒントも区別する。
- 手掛かりなしの確認では、対象表現の答えを含む補助文を表示しない。補助によって答えが推測できる場合は支援付きの結果として保存する。
- 当日の成功は次の練習を始める目安とし、後日の期限到来の復習でも成功したことを別に確認する。
- 別の場面でも使えるか確認する。単に人名を変えただけの問題を、応用力の確認とは扱わない。
- 複数の正しい表現を受け付ける。対象語を指定する課題では、その指定を明示する。

基礎用法の確認と、全文の入力確認は別カードにできる。全文入力の失敗から、どの部分が原因か分からないまま、基本動詞・周辺語の全記憶を一括で不合格にしない。

同じ用法の例文を増やしても、例文の枚数をそのまま習得用法数にしない。修了条件に使う必修用法の集合をバージョン管理し、AIが追加した周辺語によって修了までの分母が際限なく増えないようにする。修了後の復習も続け、復習での失敗によって全体の修了記録を取り消さない。

解放条件の細かな閾値は[AI登録の設計](ai-vocabulary-design.md)にある仮設定を出発点とする。FSRSは復習の時期を扱い、全用法の習得証明や会話力の証明を行うものではない。

## 写真から取り込む際のAIの役割

1. 提供された範囲を読み取り、見出し語・語義・対象用法・例文を候補として抽出する。読めない箇所は確認が必要な状態にする。
2. 対象用法と周辺語を分け、学習者の既知の用法と対応させる。既知か不明なら短い確認を挟む。
3. 必要に応じて、周辺語を易しくした練習と、別の場面の独自例文を作る。
4. 元の内容とAIによる追加・修正を区別してプレビューし、確認後に保存する。
5. 登録後は保存済みの教材を使って出題し、各皿の途中ではAIを呼ばない。

写真やそこから取り込む教材は利用者の個人デッキに置く設計とし、GitHubへは調査・設計と独自のサンプルを保存する。公開アプリの共通問題には独自の例文を用意する。今回の変更には本の本文・例文集・写真は含めていない。

最初は10用法程度で取り込み・確認・後日の復習まで試す。難しい周辺語のために止まらず、対象の用法を取り出せるかを確認してから範囲を広げる。現在の3コース・3/5/10秒設定はこの設計メモでは変更しない。
