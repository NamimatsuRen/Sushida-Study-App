# 寿司タイプ ENGLISH

## 現在の目的

寿司打の英語タイピング版として、ゲームの流れと操作感を再現する。以前の暗記カード中心の試作から、表示された英文を打ち切る回転寿司ゲームへ変更した。登録やデッキの操作を挟まず、そのまま遊べる構成。以前の設計とMarkdown例は `docs/archive/` に残し、旧localStorageキーも変更・削除しない。

## 参照した資料

- 公式の寿司打 https://sushida.net/ ：「回転寿司のお皿が流れてしまう前に文字をタイプし、どれだけ元を取れるかを競う」という中心ルール、音の設定を確認。
- コース選択の参考画面 https://note.com/masa_muranaka/n/nf437bb8c72ba ：木目の画面、5段階の難易度、3,000/5,000/10,000円と60/90/120秒の構成。
- ゲーム画面の参考写真 https://game.watch.impress.co.jp/docs/news/1462007.html ：上部の時計・連打メーター、流れる皿、中央の入力表示、下段の価格別獲得数というレイアウト。

公式ゲーム自体の自動プレイ・解析はしていない。公式ロゴ、音声、画像、単語データは取得・転用していない。寿司のSVG・木目・音・英文はこの実装用に作成した。

## 再現するゲームの流れ

タイトル → 難易度とコース → Space/Enter → 3秒のカウントダウン → 英文を1文字ずつ入力 → 時間切れなどで結果 → 同じコースへ再挑戦。

- お手軽3,000円 / 60秒：短い英単語50問。
- お勧め5,000円 / 90秒：短い英語フレーズ40問。
- 高級10,000円 / 120秒：少し長い英文40問。
- 大文字・小文字は同一扱い。単語間のスペースは必要。Enter送信やBackspace修正は不要。
- 完成した皿だけが加点される。途中の文字や見送った皿には加点しない。
- 普通：ミスしても正しいキーで続行。練習：皿がゆっくり。正確重視：ミスで現在の入力位置を先頭に戻す。速度必須：皿の見送りで終了。一発勝負：ミスまたは見送りで終了。
- コース料金を食べた皿の合計から引いて、得・損を表示。
- 正しく打ったキー数、打/秒、ミス数、正確率、逃した皿数、最高連続数、時間ボーナス、価格別枚数を記録。

## 英語版独自の調整

価格は文字数に応じて100/180/240/300/400/500円。各コースの文字数帯内を6段階に分ける。皿の持ち時間は `5 + 英文の文字数 × 0.18` 秒、練習ではその1.8倍。30文字連続正解で残り時間を2秒追加し、ミス・見送りで連続数がリセットされる。これらの定数は公式の内部計算を複製したものではなく、英語向けの初期調整。

英文と、任意で日本語の意味を表示する。句読点・数字・Shift必須文字は現段階の問題集に含めず、文字入力とスペースに集中できるようにする。句読点・大文字の厳密入力は今後の候補。

## 入力・停止・記録

- OSのキーリピートや修飾キー付きショートカットを得点にしない。
- IME入力を検知すると一時停止し、半角英数への切り替えを案内する。
- Esc・一時停止ボタン・タブ非表示・ウィンドウのフォーカス離脱で停止。再開操作まで時計と皿を動かさない。
- カウントダウン中に離脱した場合は開始待ちに戻す。
- タッチ用の画面キーボードを設定で有効化可能。
- キーボードとタッチの自己ベストは別集計。途中終了は自己ベスト対象外。直近50件と設定・ベストをlocalStorageに保存。オンラインランキングやサーバー同期はない。
- 音はWeb Audioで生成。音源や外部フォント・CDNへの依存はない。
- `prefers-reduced-motion` では皿を中央に固定し、下の残り時間バーで期限を示す。

## 検証範囲

`npm test` はモデル14ケース、DOM操作4ケース。各難易度、得点、時間ボーナス、スペース、時刻境界、一時停止、シャッフル、設定と記録、IME検知、タッチ操作を検証。JS構文チェックと差分検査も実施。管理環境に対応するブラウザQAツールがないため、ブラウザでの見た目・実際のIME・実際の音・端末のタッチ入力は未検証。
