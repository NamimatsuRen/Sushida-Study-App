# 添付コードから取り込んだ音と手応え（v0.7）

## 参照と選び方

ユーザー添付の「タイピング・キメラ（Typing Chimera）」HTML内の `SoundFX` を参照した。録音ファイルを読み込まず、Web Audioの発振器と音量の減衰で音を生成する方法を、現在の寿司タイプへ移植・調整している。実装は [`dist/sound.js`](../dist/sound.js)。外部CDN、音源ファイル、新しいランタイム依存は不要。

| 場面 | 生成する音 | 元コードとの関係 |
| --- | --- | --- |
| ボタン | 三角波、1700→450Hz、45ms | 既存の短いクリック音を保持 |
| 打鍵 | 三角波、540–620→180Hz、35ms | `playKey` の周波数の揺らぎと短い下降音 |
| ミス | のこぎり波、130→80Hz、100ms | `playMiss`、音量を控えめに調整 |
| 文字ヒント | 正弦波、330→440Hz、90ms | ヒントの開示がわかる短い音を追加 |
| 完答 | 三角波、523.25 / 659.25 / 1046.5Hz、50msずつずらす | `playPlateClear` の3音 |
| 連続完答 | 正弦波、440 / 554.37 / 659.25 / 880Hz、60msずつずらす | `playPromote` の上昇音。従来のタイムボーナスにも使用 |
| 時間切れ・答え開示 | 正弦波、659.25 / 554.37 / 440Hz、80msずつずらす | `playDemote` の下降音を小さめに調整 |
| 終了 | 三角波、261.63 / 329.63 / 392 / 523.25Hz | 結果表示の短い締めの音を追加 |

これらは操作への効果音。英単語の読み上げ・発音学習の音声ではない。

## ゲームに取り込んだ要素

- **連続完答の見える化**：追加ヒントなしの完答を数え、3皿ごとにゲージ・上昇音・短い背景色の変化で祝う。結果には今回の最長連続完答も表示する。
- **入力への小さな反応**：ミスした入力欄の色を変え、4pxだけ短く揺らす。2回ミスによる文字開示にはヒント音を使う。動きを減らす設定では揺らさない。
- **音の役割分け**：短い打鍵音、低いミス音、完答の和音で、画面を注視し続けなくても操作への反応を受け取れるようにする。

元コードの動的な昇格・降格は、学習モードでは連続完答の演出へ置き換えた。ユーザー指定の単語3秒・フレーズ5秒・例文10秒、得点、出題順、復習予定は変えない。追加ヒント付き完答・時間切れ・答え開示で連続完答は0へ戻るが、獲得済みの金額は減らさない。

連続完答は同じ周回内の手応えであり、習得度の判定ではない。既定の頭文字・文字数の手掛かりや、同日の追加練習も含む。長期定着の集計と復習予定は従来どおり別に扱う。3皿という節目や音色の好ましさは研究で確定した学習効果ではなく、遊び心地を調整する仮設定。

## 音量と実行

- 設定から音量0–100%（初期35%）を変更し、8種類の効果音を個別に試せる。ブラウザ内に保存する。
- サウンドOFF・音量0では試聴を無効にし、再生中・再生予約中の音も停止する。ミュート中に開始された音を、後から再開しない。
- ユーザー操作でAudioContextを開始・再開する。音の完了やAudioContextの再開をゲーム進行側で待たない。
- 同時発音は32声まで。連続打鍵の音が累積し続けないよう、発音終了後に接続を解除する。12ms未満の重複した打鍵音を抑制する。
- Web Audioがない場合や再開が拒否された場合も、ゲームを続けられる。

## 確認

音声ノードのモックで音色・音程・音の開始間隔、初回再生、ミュートと非同期再開の競合、音量変更、発音数の上限・後片付けを確認。DOMで試聴、設定の再読み込み、3連続の即時遷移、ヒント付き完答後のリセットを確認している。モデルで復習予定・金額・制限時間が演出に影響されないことも確認する。

対応するブラウザQAツールがないため、実際のスピーカーでの聴感・スマホの音量・視覚的な仕上がりは未検証。
