# へんてこ水族館 — TYPEQUARIUM LAB

タイピングで稼ぐ → 好きな仲間を迎える → ごはんをあげて育てる → 客足や客層が変わる、独立した育成プロトタイプ。

試用URL： https://typequarium-ren-lab.namimatsuren.chatgpt.site （所有者限定）

## 試し方

1. まめフグ1匹と開館準備金240Gから始まる。ショップでクラゲ・エイ・アザラシ・謎のおじさん・マダム・宇宙人・ロボットなどを選んで迎える。
2. 仲間を選択し、15Gでごはんをあげる。成長ポイントでLv.1→2→3と大きくなり、なかよし度も上がる。
3. 「タイピングで稼ぐ」から20秒のおしごと。正しい1文字2G、完答で12G。表現を1つ以上完答すると、その館の人数に応じた入館料も受け取れる。
4. 出会った表現を「思い出しチェック」で確認。日本語から英語を全文入力して判定。追加の答え表示を使わず正解すると、初回15G、以降3G。
5. 正確さ、速度、思い出しの結果と、買った仲間の構成が、水の雰囲気・泳ぐテンポ・育ちやすさ・客層へ反映される。

## 個性のルール

| 入力・育成の特徴 | 変わるもの |
| --- | --- |
| 仲間の数・種類・成長・なかよし度 | 同時に遊びに来る客の数。上限24人 |
| 正確さ | ロボットの来場確率、相性の良い仲間の成長、澄んだ水のテーマ |
| 速度（WPM） | 泳ぐテンポ、ペンギン客の来場確率、海流のテーマ |
| チェックでの追加ヒントなし正答 | 宇宙人客の来場確率、相性の良い仲間の成長、宇宙のテーマ |
| ミス率・仲間の多様さ | にぎやかさと、相性の良い仲間の成長・ねこ客の傾向 |
| おじさん・マダムの在館数 | それぞれの客層の来場確率 |

客には人・おばさんご一行・ペンギン・魚・宇宙人・ロボット・ねこがいる。客層は重み付き抽選で、同じ館の状態では安定する。状態が変わると新しい顔ぶれになる。仲間は最大12体、同じ種類も迎えられる。

## この試作の範囲

- 既存の寿司タイプとは独立した静的アプリ。ログイン・Supabase・既存アプリのFSRS・学習記録とは連携しない。
- 保存キーは `typequarium-lab-v1`。ブラウザ内に保存し、JSONの書き出し・読み込み・確認付き初期化に対応。
- 思い出しチェックは試作内で出会った表現の確認。長期定着やFSRSの保持率を測定するものではない。
- 個性・価格・成長・来場確率は体験を試す仮ルール。実際のユーザー属性、年齢、性別は取得・推測しない。
- 時間が経っただけで報酬は増えない。入館料は表現を完答したおしごとの終了時に一度付与。中断分は支払わず、同じセッションの二重付与を防ぐ。
- 仲間は空腹やミスで失われない。20秒の時計は一時停止・タブ離脱・中断確認中に止まる。
- キャラクターと水槽は独自のSVG。外部画像・CDN・音源ファイルは使わず、効果音はWeb Audioで生成する。

## 実行・検証

`dist/`を静的配信する。Node.js 22以上で `npm ci` → `npm test` → `npm run check`。

モデル14ケース・DOM6ケースで、購入と残高、上限、育成、客足と客層、入力・20秒の時計、停止・中断、報酬の二重付与防止、チェックのヒント扱い、保存・再読み込み、名前の無害化とCSS構文を確認する。ブラウザQAツールがないため、実機の見た目・音・IME・タッチは未検証。

主なファイル：`dist/model.js`（経済・成長・個性・来場者）、`dist/art.js`（独自SVG）、`dist/app.js`（画面・タイピング・チェック）、`dist/style.css`（見た目）。
