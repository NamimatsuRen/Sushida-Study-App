# 寿司タイプ ENGLISH

**流れるお寿司が行ってしまう前に、英文をタイプ。**

寿司打に着想を得た英語タイピングゲームです。暗記カードを登録する前の試作から、寿司打に近いゲーム中心の構成へ作り直しました。公式版とは異なります。

試遊： https://oboe-sushi-ren.namimatsuren.chatgpt.site （所有者限定）

## 遊び方

1. 「スタート」を押して、難易度とコースを選ぶ。
2. Space / Enterで開始。3秒後にお皿が流れ始める。
3. 表示された英文を1文字ずつ入力。最後まで打ち切るとお皿の金額をゲット。
4. 制限時間内にたくさん食べて、コース料金以上の得点を目指す。

| コース | 目標 | 基本時間 | お題 |
| --- | ---: | ---: | --- |
| お手軽 | 3,000円 | 60秒 | 短い英単語50問 |
| お勧め | 5,000円 | 90秒 | 英語フレーズ40問 |
| 高級 | 10,000円 | 120秒 | 少し長い英文40問 |

練習・普通・正確重視・速度必須・一発勝負の5モード。ミスなく30文字打つと2秒の時間ボーナス。金額はゲーム内のスコアで、料金は発生しません。

- 半角英数で入力。大文字・小文字はどちらでもOK。単語間はスペースが必要。
- Enterでの送信・Backspaceでの修正は不要。
- Escで一時停止。タブやウィンドウを離れても自動停止。
- 日本語の意味の表示、サウンド、タッチ用画面キーボードは設定で切り替え。
- 結果に損得・キータイプ数・打/秒・ミス・正確率・皿数などを表示。
- 自己ベスト・直近50回の記録と設定はこのブラウザに保存。途中終了は自己ベスト対象外。

## 実行と検証

ビルド・ランタイム依存なし。`dist/` を静的Webサーバーで配信します。

```sh
python3 -m http.server 8000 --directory dist
```

ブラウザで `http://localhost:8000` を開きます。自動テストはNode.js 22以上で：

```sh
npm ci
npm test
npm run check
```

## ファイル

- `dist/core.js`：時間・皿・難易度・文字判定・得点のモデル
- `dist/app.js`：画面、入力、サウンド、記録
- `dist/phrases.js`：オリジナルの英語問題130問と日本語訳
- `dist/sushi.js`：オリジナルの寿司SVG
- `dist/style.css`：木目のゲーム画面とレスポンシブ表示
- `docs/design.md`：参照資料、公式版と英語版のルールの違い、検証範囲
- `docs/archive/`：以前の暗記版の設計資料とMarkdown例

ブラウザでの視覚検証・実機IME・音・タッチの実機検証は未実施です。公式の素材や内部計算式を複製したものではありません。オンラインランキング、アカウント同期、Markdownによる問題登録は今回の英語版にはありません。以前の暗記版のブラウザ内データは保持します。
