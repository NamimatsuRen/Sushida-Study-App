# 寿司タイプ ENGLISH — 思い出して、覚える。

**頭文字と空欄を頼りに英語を思い出す、寿司タイピング学習。**

公開URL： https://oboe-sushi-ren.namimatsuren.chatgpt.site

## 学習の流れ

学習ホームのコースカードから開始、または「学習をはじめる」からコースを選択。新しい答えの確認 → 記憶から入力 → 正解と解説 → 後日の復習。

| コース | 学ぶもの | 例 | コース / お皿の時間 |
| --- | --- | --- | --- |
| お手軽 | 単語 | decision | 60秒 / 3秒 |
| お勧め | 熟語・短い組み合わせ | make a decision | 90秒 / 5秒 |
| 高級 | 例文 | i need to make a decision | 120秒 / 10秒 |

同じ12テーマを3段階、計36問用意しました。コース時間は従来ゲームと同じ定義を共有します。皿の3/5/10秒は、本家の非公開の速度式を複製した値ではなく、英語版で緊張感を出す調整値です。

- 皿の価格は英語の入力文字数（スペース込み）で、4字まで100円／7字まで180円／14字まで240円／24字まで380円／25字以上500円。初回・復習・ヒントの有無で割引せず、完答なら表示額、時間切れ・答え開示なら0円です。
- 添付コードのWeb Audio方式で打鍵・ミス・完答・連続完答などの効果音を生成。設定で音量を変え、8種類の音を試聴できます。サウンドOFF・音量0では鳴りません。
- 追加ヒントなしで3皿続けて完答すると、3つのゲージと上昇音でお祝い。待ち時間は増やさず即次へ。今回の最長連続完答も結果に表示します。
- 最初は `a____` のように頭文字と文字数を表示。
- 同じ位置で2回ミスすると `ap___` のように1文字開示。文字を表示しても、自分で打つまで先へ進みません。
- 正解したら確認クリックなしで即次へ。ヒント付き完答は約0.25秒、答えの開示・時間切れは約0.9秒で次へ流します。止めて見たいときだけ保留可能。
- 詳しい答え・例文・解説は終了後にまとめて確認。自動フィードバック中もコース時計を進めます。保留・一時停止・タブ離脱中だけ止め、復習予定は引き続き記録。
- 期限が来た問題→未学習→期限前の追加練習の順で出題。5問終了・1日3枚の制限を外し、制限時間まで周回します。開始前の答え一覧は任意で開けます。
- FSRS-6で、回答結果と前回からの経過時間に応じて問題ごとの復習時期を自動調整。初回・期限の来た復習でヒントを使った／忘れたときは10分後に学び直します。目標保持率90%はモデル上の目安です。
- 誤答後の解き直しは2問挟める場合に、その直後へ挿入。解き直し・期限前の追加練習では復習予定を延ばしません。
- 終了後は「同じコースでもう1回」で直接再スタートできます。
- 「手掛かりなしで確認」では、全文入力後にEnterで判定。頭文字・文字数・入力途中の正誤を見せません。
- 翌日以降の結果は、通常の頭文字付きと、手掛かりなしの確認を別集計します。

得点は継続のための演出です。初回の正解・追加ヒントなしの完答だけで、長期定着や会話力を証明するものではありません。

## 学習の記録

学習メニューと上部の「記録」から、直近13週間のカレンダーを見られます。

- 挑戦数が多い日ほど緑が濃くなり、今日の挑戦・追加ヒントなしの完答・連続日数を表示。
- 周回・ヒント付き・時間切れも「挑戦」に含めます。色は正答率や習得度ではありません。
- 過去の保存済み回答から日別合計を復元。以後は日別合計を別に保存し、詳細ログが2,000件を超えても合計を維持。
- 日付はこの端末のローカル日付。未記録日は空欄にし、サンプルの実績は入れません。
- 今日が未着手なら昨日までの連続日数を表示。日別の詳細は表でも確認できます。

見た目は8pxを基本に余白を統一し、細かいコントロールに4pxを使用。スマホ幅ではカードやヘッダーのボタンを組み替えます。ルールは [docs/ui-design.md](docs/ui-design.md) を参照。

## 自分の問題を登録する

学習メニューの「Markdownから問題を登録」から貼り付け、または.mdを読み込みます。

```markdown
# 自分のノート

## 「りんご」を英語で。
答え: apple
解説: an apple のように使います。

## 水の化学式は？
答え: H2O | H₂O
解説: 水素原子2つと酸素原子1つから構成されます。
```

別解は `|` 区切り。問題と各項目は1行ずつ。1デッキ最大100枚、ファイル100KBまで。自分用デッキは1つ保存でき、保存し直すと置き換えます。同じ問題・答えの説明だけを修正しても復習記録は保持します。英語以外の勉強や日本語回答にも対応。サンプルは [decks/study-example.md](decks/study-example.md)。

タイトルの「タイピングだけで遊ぶ」から遊べます。英文130問、3,000/5,000/10,000円と60/90/120秒、練習・普通・正確重視・速度必須・一発勝負の5難易度を保持しています。こちらの得点・打/秒・ミスと、学習モードの復習記録は分離しています。

## 保存と制限

ゲストの学習進捗・FSRS状態・直近2,000回答・日別合計・自作問題は、このブラウザに保存。ログイン後は利用者ごとにSupabaseへ保存し、別端末から読み込めます。初回は元のゲスト記録を残して引き継ぎ可能です。未同期分は端末に残し、他の端末との競合では上書きを止めます。Anki同期、FSRSパラメーターの個人別最適化、バックアップファイルからの復元、音声評価、問題の自動生成は未実装。ブラウザ削除でゲスト・未同期の記録は消えます。公式の寿司打とは異なる個人制作です。金額はゲーム内の演出で、お支払いは発生しません。

## ログインと公開設定

Google・メールのログイン、新規登録、パスワード再設定に対応。Supabase Authで認証し、RLSで利用者ごとの学習記録を保護します。Progateのコース中心の構成を参考に、学習ホーム・進捗・ログイン画面を整理しました。

[接続・Google OAuth・メール送信の設定手順](docs/auth-setup.md)と[認証・同期の設計](docs/auth-design.md)を参照。Project URLと公開キーを設定済み。テーブル・Googleプロバイダー・SMTPも所有者確認で設定完了です。別プロジェクトへ移す場合は接続手順に従って設定してください。

## 実行と検証

`dist/` を静的配信します。FSRS・Supabase SDKとライセンスを同梱し、実行時のCDNは不要。FSRSは端末内で計算し、ログイン・同期時にSupabaseへ通信します。通常の配信にビルドは不要です。

```sh
python3 -m http.server 8000 --directory dist
```

Node.js 22以上で自動テスト：

```sh
npm ci
npm test
npm run check
```

モデル・DOM操作で、既存ゲーム、文字ヒント、時計、復習予定、確認課題、Markdown登録を検証します。実ブラウザでの見た目・実機IME・実際の音・タッチの検証は未実施です。

認証SDKを更新するときは `npm run vendor:auth`。Supabaseの公開設定は `.env.example` を参照し、環境変数を渡して `npm run configure:auth` を実行します。Secret Keyやservice_roleキーは使いません。

主要ファイル：`dist/study-core.js`（学習モデル）、`dist/study-scheduler.js`（FSRS）、`dist/study-cards.js`（教材）、`dist/study.js`（学習UI）、`dist/core.js`（従来のゲーム）、`dist/app.js`（共通部分）、`dist/sound.js`（効果音生成）。
