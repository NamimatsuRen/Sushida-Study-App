# おぼえ寿司 / Sushida Study App

Markdownからカードを登録し、答えを思い出して入力する寿司打風の暗記アプリです。Anki・寿司打の非公式プロトタイプです。

## 使う

`dist/` を静的Webサーバーで配信するだけで動きます。例：`python3 -m http.server 8000 --directory dist` を実行し、ブラウザで `http://localhost:8000` を開きます。ビルドや依存パッケージのインストールは不要です。

- デッキ選択 → 5/10/20問 → 時間制限なし、または1問30秒を選択
- 答えを入力してEnterで確認。変換中のEnterでは送信しません
- 全角/半角、英字の大小、前後の空白を正規化して判定。別の正しい表現は手動で正解に修正可能
- 正解・別解・解説を表示して次へ。正解は1日後から間隔を倍にし上限90日、不正解は10分後
- 復習期限の来たカードを優先。全て期限前なら追加練習可能
- 間違えた問題の直後の再練習では元の復習予定を維持
- デッキの追加・編集・削除、Markdownファイルの読み込みと書き出し

## Markdown形式

```markdown
# 化学の基本

## 水の化学式は？
答え: H2O | H₂O
解説: 水素原子2つと酸素原子1つで構成されます。
```

`#` はデッキ名、`##` は問題、`答え:` は必須です。別解は `|` 区切り、`解説:` は任意。問題と各フィールドは1行で記述します。MarkdownをHTMLとして実行しません。最大500枚、ファイル500KBまで。編集したデッキの復習記録はリセットされます。サンプルは `decks/example.md` を参照してください。

## 保存と制限

カード・回答記録・直近1000セッションはブラウザのlocalStorageに保存します。端末間同期、サーバー保存、Anki同期、FSRS、ローマ字→かな変換、AI採点は未実装です。ブラウザデータの削除で記録も消えます。Markdownの書き出しに学習記録は含まれません。日本語はIMEによる確定入力を使用します。入力内容はサーバーへ送信しません。WebフォントにはGoogle Fontsを使用します（接続不可時はシステムフォント）。

## 設計の根拠

研究の根拠とプロトタイプ独自の仮説は [docs/design.md](docs/design.md) に記載。タイピングの速さと想起の正確さを分け、速度競争だけにならないようにしています。

## 検証

Node.js 22以上で `npm ci` 後、`npm test`、`npm run check`。DOM操作・回答判定・復習間隔を自動検証します。ブラウザ上の視覚・実機IME検証は公開時点では未実施です。公開先の識別情報は `.openai/hosting.json` にあります。実行時の秘密情報は含みません。
